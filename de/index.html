So gebaut, dass wir Ihr Geld nicht sehen können

  • Nur Lesezugriff

    Der Key kann nur lesen. Keys mit Handels- oder Auszahlungsrechten werden beim Verbinden abgelehnt.

  • Ende-zu-Ende-Verschlüsselung

    Ihr Journal wird auf Ihrem Gerät mit einem aus Ihrem Passwort abgeleiteten Schlüssel verschlüsselt. Unser Server speichert nur verschlüsselte Daten.

  • Direkt zur Börse

    Anfragen gehen von Ihrem Browser direkt an die Börse, nicht über unseren Server.

  • Ihre Geräte, Ihre Regeln

    Bestätigen Sie jedes neue Gerät mit einer Zahl, sehen Sie die Liste und entziehen Sie den Zugriff mit einem Tippen.

Fragen

Ist es sicher, meinen API-Key anzugeben?

Erstellen Sie einen Key mit reinen Leserechten. Buy&Sell prüft die Rechte beim Verbinden und lehnt Keys ab, die handeln oder abheben können. Der Key wird verschlüsselt zusammen mit Ihrem Journal gespeichert.

Welche Börsen werden unterstützt?

Derzeit OKX. Hyperliquid, Bybit und Binance folgen; mehrere Börsen können ein Journal teilen.

Funktioniert es auf dem Smartphone?

Ja. Öffnen Sie die Website auf dem Smartphone und fügen Sie sie zum Startbildschirm hinzu — sie funktioniert wie eine App. Computer und Smartphone nutzen dasselbe Journal.

Können Sie meine Trades sehen?

Nein. Das Journal wird auf Ihrem Gerät verschlüsselt; unser Server speichert nur verschlüsselte Dateien und kann sie nicht lesen.

Wie bezahle und kündige ich?

Tarife werden in USDT für einen Monat oder ein Jahr bezahlt; nichts verlängert sich automatisch. Nach Ablauf des bezahlten Zeitraums wechselt das Konto zu Basis, Ihre Daten bleiben erhalten.

Ist das eine Anlageberatung?

Nein. Buy&Sell zeigt Fakten aus Ihren eigenen Trades und dem Markt. Die Entscheidungen treffen Sie; Trading birgt das Risiko von Verlusten.

Hilft es bei der Steuer?

Der Steuerreport zeigt jeden geschlossenen Trade in der Währung Ihres Landes zum amtlichen Kurs am Schließungstag, mit Jahressummen und CSV-Export. Er ist keine Steuerberatung.
